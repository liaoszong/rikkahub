## ✨ 更新亮点

🖼️ 图片生成正式融入聊天：推理模型可以调用已配置的图片模型，参考用户发送的图片继续创作，并在同一段对话中呈现多张结果。

### 🎨 体验改进

- 🪄 重做图片生成状态与画廊：生成进度、已耗时和完成状态更准确，多图结果更紧凑，查看大图与切换图片更自然。
- 🧰 侧边栏重新整理“创作工具”和“聊天”，支持折叠并记住状态；图片生成、AI 翻译和设置入口更加清晰。
- 🖼️ 优化多图片消息布局，避免用户一次发送多张图片时纵向占满对话。
- 🤖 新用户可直接使用预置的 PaleInk Provider 与模型；图片模型会按能力识别，并优先选择更新的可用模型。
- ⬇️ 更新流程支持重新打开、断点恢复和已下载安装包复用；首次安装权限前增加简短说明，减少系统“未知来源”提示带来的疑虑。
- 🌍 补齐更新状态的简中、繁中、英文、日文、韩文和俄文提示。

### 🛠️ 修复与可靠性

- 🧭 修复切换对话时把“工具调用结束”误判为整轮完成的问题，后台图片任务状态不再提前变绿。
- ⏱️ 修正图片生成耗时和消息 Token 信息过早出现的问题，生成中会持续显示真实已耗时。
- 🧩 修复多图请求失败/部分成功时的状态合并、结果保存和重启恢复，图片文件会先验证真实格式与可解码性再原子落盘。
- 🧠 修复标题总结模型使用 Auto 时在单 Provider 配置下容易失败的问题，并完善模型能力与就绪状态判断。
- 🔐 加固更新签名校验、下载重定向、APK 包名/版本/签名预检、日志脱敏、Web 文件访问与备份恢复边界。
- 📦 修复数据库与图片文件在崩溃恢复时可能不一致的问题，并补充 Room 迁移、备份恢复和 exactly-once 写入保护。
- 📱 完成 Android 16 KB page size 兼容验证；Debug 构建不再需要 Firebase 客户端配置，同时保留扫码功能所需依赖。
- 🚦 新增 Linux 全模块测试/Lint 与 Windows 平台合同质量门禁，发布构建可复用 Gradle configuration cache，减少重复等待。
